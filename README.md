## DVC-пайплайн

Пайплайн состоит из четырёх стадий, запускаемых командой `dvc repro`:

```
preprocess → augment → train → train_aug
```

1. **preprocess** — загрузка Fashion MNIST, сохранение обработанных массивов
2. **augment** — аугментация (отражение, поворот, сдвиг, масштабирование), удвоение датасета
3. **train** — обучение 3 моделей на исходных данных
4. **train_aug** — обучение 3 моделей на аугментированных данных

---

## Модели

- **RandomForestClassifier** — 100 деревьев
- **LogisticRegression** — 200 итераций
- **CNN** — Conv2D(32) → MaxPool → Conv2D(64) → MaxPool → Dense(128) → Dense(10, softmax)

## Результаты

### Без аугментации

| Модель | Точность |
|---|---|
| RandomForest | 85.7% |
| LogisticRegression | 82.4% |
| **CNN** | **86.6%** |

### С аугментацией

| Модель | Точность |
|---|---|
| RandomForest | 78.1% |
| LogisticRegression | 62.7% |
| CNN | 79.2% |
